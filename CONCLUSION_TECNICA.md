# Conclusión Técnica

El curso de Administración de Linux permitió fortalecer de manera práctica los conocimientos necesarios para la gestión de sistemas GNU/Linux, mediante actividades relacionadas con la instalación y configuración de Arch Linux, administración de almacenamiento con LVM, ampliación de volúmenes, gestión de usuarios y servicios, configuración del entorno gráfico MATE y automatización de tareas mediante scripts en Bash. Estas prácticas permitieron comprender de forma integral el funcionamiento y la administración de los recursos del sistema, fortaleciendo las capacidades técnicas para ejecutar tareas de configuración, operación, monitoreo y mantenimiento de entornos Linux de manera eficiente y estructurada.
